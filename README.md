# 라스트 택시 — 마지막 피난길

설치 없이 실행하는 60초 자동차 생존 게임입니다. `index.html`을 브라우저로 열어 플레이할 수 있습니다.

- 키보드: ← / → 또는 A / D, 일시정지 P / Esc
- 모바일: 화면 아래 좌우 버튼
- 튜토리얼, 피난처 선택, 구출·회피, 2초 부스터 지원
- [최종 기획서](GAME_DESIGN.md)

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch에서 `main`의 `/ (root)`를 선택하면 정적 배포할 수 있습니다. 공개 주소는 GitHub Pages 설정이 완료된 뒤 확인합니다.
