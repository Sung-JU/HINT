# 라스트 택시 — 마지막 피난길 v8

[게임 플레이](https://sung-ju.github.io/HINT/) · [최종 기획서](GAME_DESIGN.md)

설치 없이 PC·모바일에서 실행하는 자동차 생존 게임입니다. `index.html`을 브라우저로 열어 로컬에서도 플레이할 수 있습니다.

- 좌우 키 / A·D 또는 화면 아래 버튼으로 차선 이동. P / Esc로 일시정지.
- 첫 60초에 승객을 대피시키고 이후에도 계속 달릴 수 있습니다.
- 60초 이후 **주행 종료·기록 저장**으로 언제든 끝낼 수 있습니다. 직접 종료하면 현재 승객도 대피 처리합니다.
- 연장 중 파손되어도 이미 획득한 점수와 대피 보상은 유지됩니다.
- 최고 점수와 최근 주행 10개를 같은 브라우저에 저장합니다. 서버·기기 간 동기화는 없습니다. 브라우저 데이터를 삭제하면 기록도 사라집니다.
- 기본 최고 160km/h, 누적 부스터 최대 720km/h. 피버는 1,440km/h. 속도에 따라 점수 최대 9.75배.
- 5단계 연습·스킵·규칙 다시 보기·효과음 끄기·피드백 복사 지원.

GitHub Pages의 `main` / `/ (root)`로 배포됩니다. 외부 이미지·라이브러리·유료 API는 사용하지 않습니다.

## v7 추가 규칙

- 일반 좀비를 치면 켜진 부스터 시간을 5초로 갱신합니다.
- 피버 밖에서 일반 좀비 5마리 처치 → 3초 피버·충돌 무적.
- 피버 중 방패 좀비 처치 → 기본 300점 × 속도 배율, 피버 +1초(남은 시간 최대 6초).
- 피버 동안 기존 부스터 시간은 보존하고, 끝나면 부스터 속도로 복귀합니다.
- 차량 옆 회피뿐 아니라 지나간 차량 뒤로 같은 차선에 합류해도 부스터가 발동합니다. 차량당 한 번만 보상합니다.
- 기존 v6 최고 점수와 최근 주행 기록은 자동으로 이어받습니다.

## v7.2 변경

- **Space / 승객 부스터 버튼:** 한 판에서 승객 1명→2명→3명…을 소모해 5초 최대 720km/h 부스터. 새 판에서 비용은 1명으로 돌아갑니다.
- 승객이 부족하면 차감·발동하지 않습니다. 좌석 정원은 6명이므로 비용 7명부터는 사용할 수 없습니다.
- 피버 중 사용하면 피버 속도를 유지하고 끝난 뒤 최대 부스터가 이어집니다.
- 사망·수동 종료 시 별도 전체 화면에서 최종 기록을 유지합니다. 연속 입력이 재도전·피난처 선택을 누르는 문제를 수정했습니다.
- 최종 기록 화면 안에서 피드백을 작성·복사할 수 있습니다.

## v7.3 발동 피드백

- Space 입력을 단일 캡처 경로로 처리해 버튼에 초점이 있어도 한 번만 발동합니다.
- 승객을 소모하면 실제 소모 인원만큼 택시에서 내려 가까운 길가로 이동하고 사라집니다. 다시 구출하는 게임 물체는 아닙니다.
- 문 열림·승객 감소 숫자·독립 발동 상태·불꽃·속도선·짧은 가속음이 함께 나옵니다.
- 직후 충돌했다면 최대 부스터 해제를 따로 안내합니다.
- ‘동작 줄이기’에서는 움직이는 인물 대신 감소 숫자와 상태로 알립니다. 효과음은 버튼으로 끌 수 있습니다.

## v8 순위·속도 조정

- 난이도별 **내 기록 TOP10**을 최근 주행 10개와 별도로 저장합니다. 나중에 다시 열어도 높은 순위가 유지됩니다.
- 점수 우선, 동점이면 더 긴 주행 시간 순입니다. 결과 화면에서 이번 순위와 TOP10을 확인할 수 있습니다.
- 시작 속도 **80km/h**, 감속 하한 60km/h. 일반 가속 한도 160·부스터 720·피버 1,440은 유지합니다.
- 충돌은 **현재 속도 20% 감소**입니다. 720→576처럼 감속하고 남은 부스터 시간을 유지합니다.
- 기존 최고 점수가 최근 기록에서 사라졌더라도 순위에 이어받습니다. 알 수 없는 과거 주행 시간은 ‘시간 미기록’으로 표시합니다.
- 순위는 이 브라우저 기준이며 다른 플레이어나 기기와 공유되지 않습니다.
