# 라스트 택시 — 마지막 피난길 v7

[게임 플레이](https://sung-ju.github.io/HINT/) · [최종 기획서](GAME_DESIGN.md)

설치 없이 PC·모바일에서 실행하는 자동차 생존 게임입니다. `index.html`을 브라우저로 열어 로컬에서도 플레이할 수 있습니다.

- 좌우 키 / A·D 또는 화면 아래 버튼으로 차선 이동. P / Esc로 일시정지.
- 첫 60초에 승객을 대피시키고 이후에도 계속 달릴 수 있습니다.
- 60초 이후 **주행 종료·기록 저장**으로 언제든 끝낼 수 있습니다. 직접 종료하면 현재 승객도 대피 처리합니다.
- 연장 중 파손되어도 이미 획득한 점수와 대피 보상은 유지됩니다.
- 최고 점수와 최근 주행 10개를 같은 브라우저에 저장합니다. 서버·기기 간 동기화는 없습니다. 브라우저 데이터를 삭제하면 기록도 사라집니다.
- 기본 최고 160km/h, 누적 부스터 최대 720km/h. 피버는 1,440km/h. 속도에 따라 점수 최대 9.75배.
- 5단계 연습·스킵·규칙 다시 보기·충돌음 끄기·피드백 복사 지원.

GitHub Pages의 `main` / `/ (root)`로 배포됩니다. 외부 이미지·라이브러리·유료 API는 사용하지 않습니다.

## v7 추가 규칙

- 일반 좀비를 치면 켜진 부스터 시간을 5초로 갱신합니다.
- 피버 밖에서 일반 좀비 5마리 처치 → 3초 피버·충돌 무적.
- 피버 중 방패 좀비 처치 → 기본 300점 × 속도 배율, 피버 +1초(남은 시간 최대 6초).
- 피버 동안 기존 부스터 시간은 보존하고, 끝나면 부스터 속도로 복귀합니다.
- 차량 옆 회피뿐 아니라 지나간 차량 뒤로 같은 차선에 합류해도 부스터가 발동합니다. 차량당 한 번만 보상합니다.
- 기존 v6 최고 점수와 최근 주행 기록은 자동으로 이어받습니다.
